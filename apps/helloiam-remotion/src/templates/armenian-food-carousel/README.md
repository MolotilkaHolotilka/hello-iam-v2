# Armenian Cards Carousel

Six-card MVP carousel based on the pasted JSX card layout:

`template.tsx + mapping.example.json + content.example.json + animationPreset -> props.json -> PNG/MP4`

Images in this example use files copied into `apps/helloiam-remotion/public/generated/images`.
The workflow expects exactly 6 cards for now: `card1` through `card6`.
