## 2. Что выяснили о проекте (поверх CLAUDE.md)

### Архитектура коротко

- Два приложения в монорепо:
  - [apps/post-ops-ui/](apps/post-ops-ui/) — Node.js + Express + ванильный JS-UI на `localhost:4242`. Главное окно работы.
  - [apps/helloiam-remotion/](apps/helloiam-remotion/) — Remotion (React-видео), шаблоны.
- Канонический порт — **4242**, а не 3000 (как в устаревшем README). Источник: [server.js](apps/post-ops-ui/src/server.js) + [config.js](apps/post-ops-ui/src/lib/config.js).

### Состояние постов

- 12 постов в [content/posts/](content/posts/) (001–103: hello, category-map, deep-dive).
- Большинство застряли на `prompting`/`storyboarding`. Главный блокер `ready` — `storyPackReady: false` в [content/tracker/index.json](content/tracker/index.json).
- Production-файлы есть для 010 и 011 (в `apps/helloiam-remotion/public/generated/`), полные ассеты — для 010, 011, 012.

### Два мира композиций в [Root.tsx](apps/helloiam-remotion/src/Root.tsx)

1. **Старые захардкоженные**: `HelloIamPost001` (1080×1920 story), `GreenPlateIntro`, `GreenPlateCard70/71/75`.
2. **Новые data-driven**: `TemplateRender` (1080×1080) и `TemplateRenderPortrait` (1080×1350). Оба роутят через `TemplateRenderer` → [registry.ts](apps/helloiam-remotion/src/templates/registry.ts) по `templateId`.

Все 6 текущих шаблонов в registry — это **реэкспорты `green-plate-intro/template.tsx`**. Отличаются только контентом и цветами, не визуальной механикой.

### Движок green-plate

- В [template.tsx:357 `pickCard()`](apps/helloiam-remotion/src/templates/green-plate-intro/template.tsx#L357) роль карточки выбирается **по индексу**: `0` → Hello, `last` → Brand, всё между — Quote.
- `localFrame = frame - activeIndex × segmentFrames`, где `segmentFrames = durationInFrames / cardCount`.
- `mediaSource()` сам отрезает префикс `public/` от путей → правило: пути в JSON писать как `"generated/file.png"`, без слэша и без `public/`.

### File-first persistence

- Source-of-truth — markdown в [content/posts/](content/posts/).
- UI-state — [tracker/index.json](content/tracker/index.json), пересобирается через `npm run index`.
- Run-логи в `content/runs/<postId>/*.json` — **иммутабельные**. Rollback = новый ран на старый артефакт.

### Статусы и стадии

- Status order: `planned → writing → storyboarding → prompting → asset-ready → editing → ready`.
- Content V2 stages: `brief → narrative → slides → prompts → images → export`. Одобрение стадии раскладывается на низкоуровневые tracker-флаги.

### Эмодзи — не отдельный тип ассета

- Везде поле `image: string`. Различие — имя файла и **позиция карточки**.
- Доказательство: в green-plate один и тот же `emoji-greens.png` используется и в Hello (card 0), и в Brand (card 2).

## 4. Поправка вчерашнего разбора — `assetRole` существует

В первом ответе по mapping/content я сказал «никаких полей `assetRole` нет». Это было **неверно** — файлы в репо изменились между чтениями (или я их пропустил). Что есть **сейчас**:

### Тип `AssetRole`

[types.ts:4-10](apps/helloiam-remotion/src/templates/types.ts#L4-L10):
```ts
export type AssetRole =
  | 'photo' | 'image' | 'emoji' | 'video'
  | 'photo-background' | 'photo-slide';
```

`CardBlock` имеет отдельные поля `image` и `video`, плюс `assetRole`/`assetType`.

### Компонент `Media` в green-plate шаблоне

[template.tsx:40-63](apps/helloiam-remotion/src/templates/green-plate-intro/template.tsx#L40-L63):
- `mediaPath(card)` = `card.video || card.image`
- `isVideoMedia(card)` = `assetRole === 'video'` ИЛИ путь соответствует `\.(mp4|webm|mov)`
- Если video → `<Video src muted loop />`, иначе → `<Img src />`

`Media` используется во **всех трёх** card-компонентах (Hello :151, Quote :274, Brand :366).

### Что это даёт

- Поддержка видео-ассетов **уже реализована** на всех уровнях: types → content/mapping JSON → resolver → template → Remotion `<Video>`.
- Все 6 существующих шаблонов размечены `assetRole: "image"` / `"emoji"` в content.

## 5. Smoke-test `asset-role-smoke-test`

### Что хотели проверить

`assetRole: "video"` действительно уходит в `<Video>`, а не в `<Img>`. Плюс `image` и `emoji` не сломались.

### Что нашли

- Шаблон [asset-role-smoke-test/](apps/helloiam-remotion/src/templates/asset-role-smoke-test/) уже создан кем-то ранее (5 файлов на месте).
- Видеоассет [public/generated/asset-role-test-video.mp4](apps/helloiam-remotion/public/generated/asset-role-test-video.mp4) (2 MB) лежал, готовый к использованию.
- ffmpeg на машине отсутствует, но движок Remotion умеет сам рендерить тестовое видео при необходимости.

### Подводный камень: silent fallback в `/api/render`

Первый POST с одним только `templateId: "asset-role-smoke-test"` — сервер вернул `200 OK`, но **молча подсунул** `DEFAULT_MAPPING` (для `custom-jsx-template`, 2 карточки) и `DEFAULT_CONTENT` (slides). Отрендерилось не то, что просили — квадрат с чужим текстом.

Источник: [template-workflow-service.js:192-193](apps/post-ops-ui/src/services/template-workflow-service.js#L192-L193):
```js
const mapping = parseOptionalJson(payload.mapping, "Mapping", DEFAULT_MAPPING);
const content = parseOptionalJson(payload.content, "Content", DEFAULT_CONTENT);
```

Это поведение — потенциальный баг. Лучше было бы либо требовать mapping/content явно, либо подтягивать их из `mapping.example.json`/`content.example.json` найденного шаблона по `templateId`.

**Воркараунд:** всегда отправлять полный payload (mapping + content + workflow), даже если в репо есть `.example` файлы.

### Что отрендерилось (с полным payload)

- runId: `2026-05-16T10-18-38-335Z-58bc04bd`
- Заняло ~52 секунды (3 stills + 3 split MP4 на TemplateRenderPortrait, 1080×1350, 630 frames всего).
- Результаты в [content/artifacts/renders/2026-05-16T10-18-38-335Z-58bc04bd/](content/artifacts/renders/2026-05-16T10-18-38-335Z-58bc04bd/).

## 8. Открытые вопросы / TODO

- **Silent fallback в `/api/render`** — потенциальный баг. Сейчас сервер тихо подменяет mapping/content на default. Стоит сделать либо ошибкой, либо автоподтягиванием `.example` файлов из папки шаблона по `templateId`.
- **Дублирование композиций** — есть два слоя: старые захардкоженные (`GreenPlateIntro`, `GreenPlateCard70/71/75`, `HelloIamPost001`) и новые data-driven (`TemplateRender`/`TemplateRenderPortrait`). Все 7-карточные посты используют только новые. Старые можно вычистить, если не используются — но это отдельная задача и нужна проверка.
- **`pickCard()` по индексу** — роль карточки сейчас определяется позицией. Если в будущем нужно будет более гибко (например, два emoji в одном посте), стоит вынести роль в content/mapping как явное поле, и сделать `pickCard` опциональным fallback'ом.
- **Размер репо 2.4 GB** — `apps/post-ops-ui/node_modules/` закоммичен в git, плюс 118 MB исходников Стаса. Для zip-архива нормально, для git-клона тяжело. Не критично, но к сведению.
